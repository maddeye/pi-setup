# Investigation

The result is a cited answer or recommendation. Do not edit code.

1. Read and apply [`how`](../../how/SKILL.md).
2. If the question asks about motivation, history, or a regression, also read and apply [`why`](../../why/SKILL.md).
3. Inspect the real source and runtime evidence. Separate facts from inference.
4. Answer the question directly. Cite file paths, symbols, commands, or history that support the answer.

Completion check: the answer follows the relevant flow end to end and every material claim points to evidence.
