# Skill authoring

The result creates or changes instructions for agents.

1. Read [`writing-for-agent`](../../writing-for-agent/SKILL.md) and every linked file it requires.
2. Read and apply [`unslop`](../../unslop/SKILL.md).
3. Inspect existing related skills before writing. Reuse their structure, not their content.
4. Keep one source of truth for each rule. Add only instructions that change agent behavior.
5. Validate the frontmatter, links, paths, and referenced skill names.
6. Show the draft or diff before broad or unclear edits. Save after approval.

Completion check: the skill has valid frontmatter, every pointer resolves, each step has a clear finish condition, and no rule is duplicated.
